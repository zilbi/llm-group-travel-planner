# LLM-Based Group Travel Planner

Applied AI project developed as a T-Bank case study at the School of Programming and Data Analysis.

## Overview

This project developed a multi-user travel planning tool that combines participants’ preferences and constraints into shared itinerary options.

The system processes user chat input, extracts trip parameters, generates itinerary suggestions with YandexGPT, and provides booking and flight links.

## Scope of Work

The project included:

- chat parsing;
- extraction of travel preferences and constraints;
- YandexGPT-based itinerary generation;
- generation of booking and flight links;
- preparation and presentation of the final project.

## Repository Structure

- `commands/` — Telegram bot commands and user interaction logic.
- `ml/` — LLM-based itinerary generation and AI-related components.
- `db/` — database models and storage logic.
- `requirements/` — dependency files.
- `main.py` — application entry point.
- `Dockerfile` — container configuration.
